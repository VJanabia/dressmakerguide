# Design system

One stylesheet, no framework, no build step for CSS. Everything lives in
`public/assets/styles.css` and is copied to `dist/assets/styles.css` on build. Edit the source only.

## Why hand-written CSS

The site is a static generator with zero dependencies. Adding Tailwind or a component library would
mean a build pipeline, a config file and a toolchain to keep alive, to produce something a few
hundred lines already do. The trade-off is that the file has to stay organised, which is what the
comments and the token layer are for.

## Typefaces

Three variable fonts, self-hosted from `public/assets/fonts/` (SIL Open Font License, commercial
use permitted). Downloaded by `python scripts/fetch-fonts.py` as a single WOFF2 per family,
subsetted to the characters the site actually uses — about 230 KB total, two files preloaded.

| Token | Family | Used for | Why |
| --- | --- | --- | --- |
| `--display` | **Fraunces** | wordmark, H1, H2, card titles | A serif with real personality, so headings carry the brand instead of a system default |
| `--serif` | **Newsreader** | body copy | Designed for long-form reading; tall x-height keeps 70ch comfortable |
| `--sans` | **Inter** | nav, tables, labels, buttons, eyebrows | Neutral and highly legible at small sizes, where a serif gets fussy |

Fallback stacks are complete, so a blocked font request degrades to Georgia / system-ui rather than
to Times New Roman.

**Rule:** body copy is never Inter, and UI chrome is never Newsreader. Mixing them is the fastest way
to make the page look accidental.

## Colour

| Token | Value | Role |
| --- | --- | --- |
| `--paper` / `--paper-2` | `#fdfbf8` / `#f7f1ec` | page and footer background — warm, not white |
| `--surface` / `--surface-2` | `#ffffff` / `#fbf7f4` | cards, tables, raised blocks |
| `--ink` / `--ink-2` / `--ink-3` | `#231a26` / `#544a58` / `#7d7286` | headings, body, meta text |
| `--plum` / `--plum-dark` | `#7d2b4a` / `#5c1b33` | links, buttons, brand |
| `--rose` | `#b95b7d` | rules, kickers, hover states |
| `--gold` | `#8a6516` | caution callouts only |
| `--green` | `#2f6b4f` | status dots only |

Shadows are warm-tinted (`rgba(92,27,51,…)`), never neutral grey. A grey shadow on a cream page is
the single most common tell of an unstyled site.

## Structure tokens

- `--wrap: 1140px` — the outer container
- `--measure: 70ch` — paragraph width. Applied to `p` and `.faq p`, deliberately **not** to tables,
  figures or lists that need the full column
- `--gut` — horizontal gutter, fluid
- `--sect` — section spacing, fluid
- `--radius` / `--radius-sm` / `--radius-pill` — 16 / 11 / 999px

## Page skeleton

```
header.site-head            sticky, blurred, brand + nav
nav.crumbs                  breadcrumbs (BreadcrumbList JSON-LD is emitted by layout.mjs)
header.page-head            eyebrow, H1, optional lede, review date
ul.facts                    optional six-tile fact strip
div.layout[.has-toc]        grid: article + optional aside.toc
  article.prose             the rendered body
  aside.toc                 "On this page", generated from the H2s in the body
footer.site-foot            link columns + fan-site disclaimer
```

The table of contents is generated by `tocHtml()` in `src/lib/layout.mjs` from the H2s actually
present, so it can never link to a section that does not exist. Pages with fewer than three H2s get
none; a page can opt out with `toc: false`.

## Page-level content fields

Set on the exported `page` object in `src/pages/*.mjs`:

| Field | Effect |
| --- | --- |
| `eyebrow` | small uppercase kicker above the H1 |
| `lede` | standfirst paragraph under the H1 |
| `facts` | array of `[label, value]` tiles under the head — keep every value to a verified fact |
| `toc: false` | suppress the table of contents |
| `preload` | hero image to preload with high priority |

## House rules

1. **No raw HTML in page bodies.** The Markdown subset in `src/lib/md.mjs` is the only way in, which
   keeps content portable and escaping honest.
2. **A table needs a blank line before it and adjacent row lines.** `renderMarkdown` only recognises a
   table when the rows are contiguous — split them across array elements and the table silently
   disappears.
3. **Markdown emphasis in `FAQPage` schema must match the visible answer.** The audit compares the two
   after normalising quotes and emphasis; it fails loudly if they drift.
4. **Alt text comes from the registry.** `src/data/images.mjs` holds one approved alt per file and the
   audit fails if a page disagrees.
5. **Fluid type, no fixed breakpoints for text.** Sizes use `clamp()`; breakpoints are reserved for
   layout changes (the TOC rail at 1080px, the bleed figure at 1220px).

## Checking a change

```bash
npm run build && npm run audit && npm run verify
npm run serve                     # then look at it
```

For a visual check without a browser window, render the built site headlessly:

```bash
node scripts/serve.mjs 4173 &
"/c/Program Files/Google/Chrome/Application/chrome.exe" --headless --disable-gpu \
  --hide-scrollbars --no-proxy-server --virtual-time-budget=7000 \
  --window-size=1440,2600 --screenshot=/tmp/home.png http://127.0.0.1:4173/
```

Screenshots from the design passes are kept in `docs/ui-review/` for comparison.
